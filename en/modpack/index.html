How to install

Download

Press “Download” at the top of the page — you’ll get the WB_26.exe file.

Close the game and run it

The installer finds your game folder by itself. If it doesn’t, pick it with “Browse…”.

Pick your mods

Tick the boxes and press “Install”. Launch the game — the mod list will be in the garage.

  • The modpack is built for the current game version. If the game has updated and the modpack hasn’t yet, the installer won’t let you install the old mods — wait for the update on this page.
  • Your mod selection is remembered — after a game update the ticks stay the same.
  • Before installing you can clean the mods and res_mods folders and the game cache and logs — game and mod settings stay.
  • Windows may warn about an unknown file (SmartScreen) — press “More info” → “Run anyway”.
